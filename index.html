01

Enterprise Network Infrastructure Lab, Cisco Packet Tracer

Featured project

The flagship project: a multi-site network with Cisco routers and switches, six VLANs, inter-VLAN routing, OSPF, DHCP, NAT, and ACLs, tested end to end.

Type
Virtual lab, Cisco Packet Tracer
My scope
Designed and configured the network
Validation
End-to-end connectivity testing across the sites

Simplified logical view. It shows how the project is organized, not an exact device inventory.
Architecture
A multi-site design with Cisco routers and switches. A WAN link joins the sites, and the main site's switching carries all VLANs.
VLAN segmentation
Six VLANs: 10 IT, 20 HR, 30 Finance, 40 Sales, 60 Server Farm, and 99 Management. EtherChannel bundles links between switches.
Routing
Inter-VLAN routing provides each VLAN's gateway, OSPF exchanges routes between sites, and each segment has its own IP addressing.
Network services
DHCP assigns addresses on the Sales VLAN, and NAT translates private addresses at the network edge.
Security
Access control lists restrict traffic between segments so only permitted flows pass.
Validation and troubleshooting
End-to-end connectivity was tested across the sites, with troubleshooting at each segment.

03

SHALFA, Unmanned Surface Vessel Prototype

A conventional RC marine platform transformed into an integrated system that combines embedded systems, computer vision, sensing, autonomous control, and communication. It was my graduation project, physically assembled and functionally tested.

Type
Engineering graduation project
My scope
Led development of the prototype
Validation
Physically assembled and functionally tested
Illustrative graphic, not real detection output.
Patent application submitted to SAIPSafe mission simulation, no real weapons or hazardous materials

The vessel senses its surroundings with a camera and a thermal sensor, locates itself with GPS, and decides how to move through manual or autonomous control. A custom web interface keeps the operator informed in real time.

It represents the journey from concept to a real engineering prototype, and a foundation for future unmanned marine systems. The software is written primarily in Python.

Technical details: architecture, components, and diagram
STEP 1

Sensing

Camera, MLX90640 thermal sensor, and GPS positioning feed the system with live data.

STEP 2

Raspberry Pi 4

The main processing and control unit, running YOLOv5 detection and tracking in real time.

STEP 3

Control

Manual and autonomous operation with differential motor control and Smart Escape.

STEP 4

Web interface

Live camera feed, thermal visualization, GPS information, and system status.

Computer vision

YOLOv5 performs real-time target detection and tracking on the camera feed.

Thermal sensing

An MLX90640 thermal sensor adds heat-based awareness, shown as a thermal visualization.

GPS positioning

GPS provides position information for navigation and display in the interface.

Manual and autonomous modes

The vessel can be driven by an operator or controlled autonomously, using differential motor control.

Smart Escape

A recovery behavior that gets the vessel moving again when forward movement is obstructed.

Mission simulation

A safe simulation using LED indicators and audio effects. No real weapons or hazardous materials are involved.
